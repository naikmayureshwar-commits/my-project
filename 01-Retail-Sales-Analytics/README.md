Retail Sales Analytics using MySQL

Project Overview

This project analyzes retail sales data using MySQL to identify sales trends, evaluate profitability, and generate actionable business insights.

The project uses a retail sales dataset containing 1,000 transactions from 2025, along with a customer master table for customer-level analysis.

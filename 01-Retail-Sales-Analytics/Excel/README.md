# Retail Sales Analytics — Excel Dashboard

## Project Overview

An Excel-based retail sales analytics project using 1,000 transaction rows from 2025. The workbook focuses on data quality validation, business performance analysis, KPI reporting and interactive dashboard development.

## Tools Used

- Microsoft Excel
- Excel Tables
- PivotTables and PivotCharts
- Slicers
- Excel formulas and KPI calculations

## Key Features

- Data quality checks and validation
- Sales and profit KPI summary
- Regional and category performance analysis
- Product-level sales and profit analysis
- Monthly and quarterly trend analysis
- Sales channel, customer segment and payment method analysis
- Interactive dashboard with slicers
- Business insights and recommendations

## Key Findings

- Total sales: ₹26,693,247.13
- Total profit: ₹5,218,087.13
- Overall profit margin: 19.55%
- Total quantity sold: 2,004 units
- Transaction rows analyzed: 1,000
- Electronics accounted for approximately 82.9% of total sales.
- Q4 was the strongest quarter by sales and profit.
- Store sales had a higher profit margin than Online sales.

## Business Value

The project demonstrates how Excel can be used to validate data, summarize business performance, compare operational dimensions, identify trends and communicate findings through an interactive dashboard.

## Files

- `Retail_Sales_Analytics.xlsx` — Excel workbook containing the dataset, analysis sheets, KPI summary, dashboard and business insights.
